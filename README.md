# Career Simulator 🎯

A hackathon project that helps users explore suitable career options based on their interests, preferred work style, risk tolerance, salary expectations, and job demand preferences.

## 📌 Project Description

Career Simulator is an interactive career guidance application built using Python and Streamlit. It asks users a few simple questions about their interests and career preferences and provides career suggestions based on their responses.

The goal is to make career exploration easier, interactive, and personalized.

## ❗ Problem Statement

Students often find it difficult to choose a suitable career because there are many career options available.

They may not know:
- Which careers match their interests
- What type of work environment suits them
- How important salary should be in their decision
- How job demand affects career choices
- Which career paths match their preferences

Career Simulator provides a simple and interactive way to explore these choices.

## ✨ Features

- 🎯 Interest-based career suggestions
- 💼 Preferred work-style selection
- 📊 Risk tolerance slider
- 💰 Salary importance rating
- 📈 Job demand importance rating
- 🔍 Interactive Streamlit interface
- 💡 Multiple career options for exploration

## 🛠️ Technologies Used

- Python
- Streamlit
- Python data structures and logic
